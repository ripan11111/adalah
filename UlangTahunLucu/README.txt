# Template Web Ulang Tahun Lucu (Pink & Green Pastel) 🌸🌿

Selamat! Folder ini berisi template website ucapan ulang tahun interaktif bertema pastel pink dan pastel green yang lucu & banyak animasi.

## 📁 Struktur Folder:
UlangTahunLucu/
 ├── index.html        (File utama website ucapan ulang tahun)
 ├── README.txt        (Petunjuk penggunaan)
 └── assets/           (Folder opsional untuk menyimpan foto-foto)

## 🚀 Cara Menjalankan:
1. Extract file **UlangTahunLucu.zip** ke laptop/komputer kamu.
2. Buka folder **UlangTahunLucu**.
3. Klik 2x pada file **index.html**.
4. Website akan langsung terbuka di web browser kamu (Chrome, Edge, Safari, Firefox)!

## ✏️ Cara Mengedit Pesan:
1. Klik kanan pada file `index.html` -> pilih **Open With** -> **Notepad** (atau **VS Code**).
2. Cari teks ucapan ulang tahun pada bagian `<div class="modal-body">`.
3. Ubah teks pesan sesuai ucapan spesial yang ingin kamu sampaikan.
4. Simpan (`Ctrl + S`) dan refresh browser kamu!
